# SLA DOUBLEW

Herramienta estática para contratación y seguimiento de SLA DOUBLEW.

## Accesos

- `index.html`: entrada principal.
- `contratacion-sla-doublew.html`: contratación, cálculo económico y dossier contractual.
- `control-seguimiento-sla-doublew.html`: registro de incidencias y consumo de bolsa SLA.

## Publicación

El proyecto no requiere servidor ni dependencias. Puede publicarse directamente con GitHub Pages desde la rama principal.
